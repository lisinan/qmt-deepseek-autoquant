1 · 执行效率与工程健康（保障项目执行效率）

发现并定位一个会阻断实盘引擎启动的环境陷阱：自动化 shell 默认 python 解析到 WorkBuddy 托管的 Python 3.13，缺少 requests，触发 ModuleNotFoundError: urllib3.packages.six.moves，导致 main.py 在 import 阶段崩溃、引擎完全起不来。

结论：本项目必须在 conda env qmt（Python 3.9，含 xtquant）下运行——路径 C:\Users\lisinan\.conda\envs\qmt\python.exe。settings.py 把 QMT 站点包追加到 sys.path 尾部，conda 的 requests 优先命中，故该环境下 main.py --snapshot 正常（已实测验证）。

日志轮转加固（已并入 main.py）：新增 _SafeRotatingFileHandler——当日志文件被已运行的 live/paper 引擎占用时，doRollover 的 os.rename 原会抛 PermissionError[WinError 32] 并从每条日志的 emit 冒出，实盘每 tick 打日志时反复抛 traceback、浪费 CPU、污染日志。现捕获后跳过轮转（流自动重开到同一文件、日志不丢）。

2 · 新候选实验：动量排名加权仓位（momentum_weight）

动机：横截面动量具有持续性（Jegadeesh-Titman），在前 5 名持仓内按动量大小做 rank-weight（强者更大、弱者更小，均值=1），把资本集中于动量最确定的名字，理论可提升风险调整后收益。该旋钮已在引擎实现，但此前无验证结论——本轮回测其是否真能改善样本外。

基准 = 当前已验证生产配置（regime 创业板指 MA60 + force_exit + trend 骑行 + 波动率目标 + max_positions=5）；候选 = 基准 + momentum_weight=True。
