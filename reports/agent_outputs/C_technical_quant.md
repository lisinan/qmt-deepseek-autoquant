   - 近N日涨跌幅 = close[t]/close[t−N] − 1；年内涨跌幅 base = 2025 年最后交易日收盘
   - MA_k = 最近 k 日收盘简单均值；60日动量 = close[t]/close[t−60] − 1（与 `momentum_lookback=60` 一致）
   - **ATR(14) = 最近 14 日 TR 的简单均值**（非 Wilder 平滑），TR = max(H−L, |H−前收|, |L−前收|)
   - 量能比 = mean(vol, 近20日) / mean(vol, 前20日即 [t−40, t−20))
   - 距60日高回撤 = close[t]/max(high, 近60日) − 1；年内位置 = (close−年内低)/(年内高−年内低)
