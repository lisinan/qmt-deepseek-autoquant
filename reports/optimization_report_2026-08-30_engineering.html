③ 可移植性（迁移机器无需改源码）

  • QMT 路径环境变量化：QMT_PYTHON_PATH / QMT_USERDATA_PATH / 以及 conda dll 路径 QMT_CONDA_ENV 现均可用环境变量覆盖，保留本机默认值。换机器只需设环境变量，不动 settings.py。

④ 稳定性（无人值守不静默死）

  • 单轮异常隔离：event_engine.run() 主循环对 _run_once 包 try/except——此前任一轮抛出未捕获异常都会冲出主循环、直接杀死整台引擎（已多次实测静默退出）。现在一律捕获、记系统提示、继续下一轮，单点故障不再连累全局。

⑥ 运维指引（保障可执行）

重要发现：本轮观测到全机 0 个 python 进程、此前良引擎 33480 已 dead——后台引擎的生命周期绑定启动它的 shell/自动化会话，跨回合会被回收。 因此「保障可执行」须在用户真实桌面持久会话（或计划任务 / 服务）中启动引擎，而非依赖自动化一次性后台启动。

在本机真实桌面启动（推荐）

conda activate qmt
cd C:\Users\lisinan\Desktop\qmtIDE-deepseek
python main.py --strategy portfolio        # 组合策略；或 --strategy single

自动化 shell 内 xtdata 不可达（回落 mock，get_ticks 在 mock 下会阻塞），故实盘引擎必须于能连 xtdata 的会话启动。

set QMT_USERDATA_PATH=D:\miniQMT\userdata_mini
set QMT_CONDA_ENV=D:\conda\envs\qmt
D:\conda\envs\qmt\python.exe main.py --strategy portfolio

python main.py --strategy portfolio   # 重新启动即加载本轮全部工程改进
