## 一、为什么不能「直接买」

先把算术摆出来，因为它决定了方案形态，也决定了为什么必须新开一条通道：

| 项 | 数值 |
|---|---|
| 账户总资产（11-02 收盘） | **63,207.98 元**（100% 现金，无持仓） |
| 300308 收盘价 | **550.00 元** |
| 一手（100 股）金额 | **55,000 元** |
| 一手占总资产 | **87.0%** |
| 策略单仓上限 `max_single_position_pct` | **0.40** ⇒ 25,283 元 |
| ⇒ `PositionSizer.size()` 算出 | `min(风险预算 2,528 / 止损距离 0.233, 25,283, 400,000)` = 10,857 元 → **0 股** |
| ⇒ 即便绕过 sizing，`RiskManager.can_open` | `pos_ratio 0.87 > 0.40` → **拒绝** |

**结论：在 40% 单仓上限下，「接回一手」不是价格问题，是数学上不可能。**
调价格、调金额、调观察篮都不会有用——每一路都会得到 0 股 + 一条 `pos_ratio>0.4` 的拒绝记录。

## 二、实现：独立、有界、会过期的 `owner_reentry` 通道

配置在 `config/settings.py::STRATEGY_PARAMS["owner_reentry"]`：

```python
"owner_reentry": {
    "code": "300308.SZ",
    "lots": 1,                  # 1 手 = 100 股（= 被误卖的原持仓数量）
    "min_price": 537.0,         # 低于此价不接
    "max_price": 545.0,         # 高于此价不追
    "max_amount": 56000.0,      # 金额硬上限
    "earliest": "09:35",        # 避开开盘 5 分钟
    "latest": "14:50",          # 不参与尾盘
    "valid_until": "2026-11-03",
}
```

执行逻辑（`engine/event_engine.py::_owner_reentry_step`）：
每个 tick 检查一次（**不受** 5 分钟入场节流限制），全部条件满足即按现价买入 100 股。

**只跳过 `max_single_position_pct` 这一条**。以下全部照常生效：
熔断 / 日内交易次数上限 / 现金夹紧（含 5% 预留）/ 行情新鲜度（120s）/ 总资产可信度（券商口径）/ `max_order_amount`。

## 三、价格为什么定在 537 ~ 545

### 当前位置（11-02 收盘）

| 指标 | 数值 | 含义 |
|---|---|---|
| 收盘 | 550.00 | 当日 −0.54%，盘中低 542.51 后拉回 |
| MA5 / MA10 / MA20 / MA60 | 579.67 / 599.03 / 665.50 / 821.22 | **完全空头排列**，四条均线全在价格上方 |
| 距 MA20 / MA60 | −17.4% / −33.0% | 深度超跌 |
| 近 20 日涨跌 | **−32.5%** | |
| 距 60 日最高（1033.89） | **−46.8%** | 接近腰斩 |
| ATR14 | 44.15（**8.03%**） | 极高波动，日均振幅 ±4.4% |

### 关键价位

- **537.00**：近 20 日最低（10-30 盘中低点），也是这波下跌的**前低**。
- **542.51**：11-02 盘中低点。注意它**高于** 537 ⇒ 最近两个低点是 **higher low（低点抬高）**，短线止跌迹象。
- **545**：11-02 收盘 550 下方 0.9%，落在前低之上、且比今日低点仅高 0.5% ⇒ 大概率能触及。

### 定档理由

- **上限 545（不追）**：现价 550 直接买属于「追反弹」。昨日误卖价是 548.61，545 已经比它便宜 0.7%；再往上就变成「为了接回而多付钱」。
- **下限 537（不接）**：跌破前低 = 支撑失守。此时在下跌通道里买入是接飞刀，与「接回底仓」不是一回事。**跌破后引擎会发一条告警而不是下单**，你可以再决定是否下调 `min_price` 强接。
- **不加「右侧确认」条件**：站上 MA5（579）需要涨 5.3%，那已经是追涨，不符合「接回来」的成本意图。

### 不同成交价的后果

| 成交价 | 占用资金 | 占总资产 | 剩余现金 | −18% 灾难止损时最大亏损 |
|---|---|---|---|---|
| 545 | 54,500 | 86.2% | 8,708 | 9,810（权益 15.5%） |
| 540 | 54,000 | 85.4% | 9,208 | 9,720（权益 15.4%） |
| 537 | 53,700 | 85.0% | 9,508 | 9,666（权益 15.3%） |

## 四、必须知道的三件事

1. **这是一次 87% 集中度的单票押注。** 策略设计意图是单票风险 ≤ 权益 7.2%（40% × 18%），本单是 **15.5%**，整整 2.15 倍。这是 OWNER 的自主决定，**不是策略信号**（当前该票 `trend_up=False`，四条均线全在上方，策略自己永远不会买它）。
2. **买入后自动进入「退出豁免」**：`exit_exempt_codes` 已含 300308 ⇒ 不再受趋势破位 / 120 日超时 / 单日暴跌 −3.25% 影响，**只受 −18% 硬止损**（约 447 元触发，按 545 成本计）。
3. **这是最后一天**：`valid_until = 2026-11-03`。若明天价格始终在区间外（或破位告警），单子到期作废，引擎只发一次「已过期」告警，之后不再尝试。收工后应把 `owner_reentry` 置为 `{}`。
